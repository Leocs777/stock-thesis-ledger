隐私

数据保存在你选择的服务端。

生效日期：2026 年 8 月 27 日 · 适用于开源 v0.2.1 参考版本。

谁负责数据

开源维护者不运营托管版 Stock Thesis Ledger，也不会从参考版本接收数据。你自行选择并运行 Server URL。如果服务器由其他个人或机构运营，请向该运营者了解其数据处理方式。

应用处理的数据

你选择的服务器会保存账户邮箱、密码校验值、偏好、自选股、研究记录、Paper 计划和订单、日志、设备注册及同步历史。iOS 在 UserDefaults 保存 Server URL、语言和通知偏好，并在设备 Keychain 保存登录令牌。

外部数据源

本地服务器可能把股票代码和你配置的 API 凭据发送给 Alpha Vantage、SEC EDGAR 和 Alpaca Paper/IEX 等提供商，相关处理受其隐私政策约束。本版本的券商写操作仅限 Alpaca Paper。

保留与删除

记录会保留在所选服务器，直到服务器运营者删除。你可在 iOS 的“设置 → 危险区域 → 删除账户和全部记录”请求从该服务器删除账户并退出所有设备。删除 iOS App 也会清除本机应用数据。

联系

安全问题请按照项目 SECURITY.md 的非公开流程报告；其他问题请访问支持页面。
