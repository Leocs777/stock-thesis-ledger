支持

先确认本地服务端。

Stock Thesis Ledger 是自行托管的开源参考项目。

连接检查

  1. 确认 Mac 上的 python3 app.py 仍在运行。
  2. http://127.0.0.1:8000 仅适用于同一台 Mac 的浏览器或模拟器。
  3. 实体 iPhone 需要在 Server URL 输入经过身份验证的 HTTPS 隧道地址。
  4. 运行应用内连接测试，并查看数据来源与时间戳。

获得帮助

请先搜索现有问题，或在 GitHub Issues 提交可复现的问题。不要附上密码、API 密钥、会话令牌、个人持仓或私有 Server URL。

安全问题

漏洞不要提交公开 Issue，请使用 SECURITY.md 中的非公开报告方式。
