Support

Start with the local server.

Stock Thesis Ledger is a self-hosted open-source reference project.

Connection checklist

  1. Confirm python3 app.py is still running on the Mac.
  2. Use http://127.0.0.1:8000 only in the Simulator or browser on that Mac.
  3. For a physical iPhone, enter an authenticated HTTPS tunnel URL in Server URL.
  4. Run the in-app connection test and read the displayed source timestamp.

Get help

Search existing issues or open a reproducible bug report on GitHub Issues. Never include passwords, API keys, session tokens, personal portfolio data, or private server URLs.

Security

Do not open a public issue for a vulnerability. Use the private reporting instructions in SECURITY.md.
